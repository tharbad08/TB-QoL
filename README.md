# TB-QoL

JSON-only quality-of-life and compatibility mods for Timberborn.

## Included mods

### Tunneling Menu Fix (v1.1.0)

Moves tunnel-related construction tools from **Landscaping → Dynamite** (More Groups) to **Tunneling** (More Tunnels / More Mines) without changing costs, unlock requirements, or construction behavior.

- [Mod folder](./TB_Tunneling_Menu_Fix)
- [Installation instructions and requirements](./TB_Tunneling_Menu_Fix/README.md)
- [Targeted templates](./TB_Tunneling_Menu_Fix/TARGETED_TEMPLATES.md)

**Install:** Copy the entire `TB_Tunneling_Menu_Fix` directory into your local Timberborn `Mods` folder. Keep the required Workshop mods installed and enabled.

**Status:** Blueprint syntax and target names were statically checked for Timberborn 1.1; in-game testing is still required.
